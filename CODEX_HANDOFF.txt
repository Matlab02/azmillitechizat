1. NÖVBƏTİ CODEX ÜÇÜN QISA PROMPT
======================================================================

Bu repo AZ Milli Təchizat saytının production mənbə kodudur. İşə başlamazdan
əvvəl bu CODEX_HANDOFF.txt faylını, README.md, DESIGN.md və UX-CONTRACT.md
sənədlərini tam oxu. Mövcud dizaynı və Azərbaycan dilində interfeysi qoru.
Frontend dəyişikliklərindən sonra `node scripts/build-bundle.mjs` işlət, çünki
canlı HTML səhifələri assets/js/app.bundle.js faylını istifadə edir. Məxfi
server və databaza məlumatlarını repoya yazma. Dəyişiklikləri əvvəl lokal,
sonra canlı saytda desktop və mobil ölçüdə yoxla.

======================================================================
2. TEXNOLOGİYA VƏ ARXİTEKTURA
======================================================================

- Frontend: HTML, CSS və vanilla JavaScript.
- Backend: PHP 8 və PDO.
- Databaza: MySQL/MariaDB, utf8mb4.
- Production JS: assets/js/app.bundle.js.
- Mənbə modulları: assets/js/api.js, storage.js, ui.js, pages.js, admin.js.
- Public API: api/index.php.
- DB sxemi və ilkin seed: api/install.php.
- Məxfi konfiqurasiya public web root-dan kənarda app_private/config.php-dədir.
- Public məhsul şəkilləri uploads/media altında, müraciət əlavələri isə
  app_private/uploads altında saxlanılır.
- Sayt ayarları azmt_site_settings, footer keçidləri azmt_footer_links
  cədvəlindədir.

6. LOKAL İŞ VƏ BUILD
======================================================================

Tələb: Node.js və PHP 8 + MySQL.

JS syntax yoxlaması:

  node --check assets/js/api.js
  node --check assets/js/storage.js
  node --check assets/js/ui.js
  node --check assets/js/pages.js
  node --check assets/js/admin.js

Bundle yaratmaq:

  node scripts/build-bundle.mjs

Vacib: source modulları dəyişdirib bundle yaratmadan deploy etmə.

Server quraşdırması üçün api/config.example.php-dən nümunə götür, amma real
DB istifadəçisi, parol, install token və hosting girişlərini heç vaxt Git-ə
commit etmə. Canlı giriş məlumatları bu sənəddə qəsdən yoxdur.
